# automatic_video_recorder

## Installation

```bash
git clone https://github.com/hanamuura/automatic_video_recorder.git
```

```bash
cd automatic_video_recorder
```

```bash
python3 -m venv .venv
```

```bash
. .venv/bin/activate
```

```bash
pip install playwright
```

```bash
playwright install --with-deps chromium
```

```bash
python3 capture_video.py
```
